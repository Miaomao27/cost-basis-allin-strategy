# 定投成本线梭哈策略：跌到成本线就梭哈，能赚钱吗？

> **如果一只基金跌得比你自己的"定投平均成本"还低 20%，你该不该把手里所有钱一次全砸进去？**
>
> 跌 8% 才买还是跌 20% 才买？涨 4% 就跑还是涨 40% 才跑？用多久的定投来算"成本线"最准？
>
> 我们用**4 个资产 × 3200 组参数 = 12800 次全历史回测**，把这个"抄底梭哈"的冲动，量化成一个可验证的问题。结论有惊喜，也有陷阱——**红利低波真的有效，纳指 100 却是骗局**。

## 🤔 这个项目回答什么问题

1. **"定投成本线"能不能当红绿灯？** 价格跌破自己定投平均成本，是不是真的意味着"便宜了、该买了"？
2. **梭哈到底靠不靠谱？** 跌到阈值满仓抄底、涨回阈值全部离场——这套"模式A"在真实历史上是赚钱还是亏钱？
3. **不同资产该用不同参数吗？** 低波的红利股和暴涨暴跌的纳指，最优"跌多少买、涨多少卖"一样吗？
4. **那些漂亮的回测数据，是真规律还是过拟合？** 我们设了"至少交易 10 次"的门槛，挡住"触发 2 次就吹出 Calmar 30+"的假象。

---

## 💡 核心想法

**定投成本线** `CB = K / U` 是你滚动窗口内所有定投的份额加权平均价——一条跟着你真实仓位走的"自适应慢均线"。

- `dev = P / CB − 1` = 现价相对你成本线的偏离度
- 现价跌破成本线 `d%` → **全额买入**（市场相对你的成本严重低估）
- 从买入后低点反弹 `+p%` → **全额离场**

这是对永久投资组合"季度再平衡"（按日历触发）的**事件驱动**升级——按价格极端状态触发，而不是按日子。

## 📊 结果总表

| 资产 | 最优参数 (W,d,p) | 梭哈Calmar | 买入持有Calmar | 梭哈年化 | 梭哈最大回撤 |
|------|:--------------:|:---------:|:-------------:|:-------:|:----------:|
| **红利低波50** | (12月, 8%, 16%) | **0.319** | 0.091 | 6.13% | **−19.2%** |
| 纳指100 | (3月, 12%, 2%) | 1.523 ⚠️ | 0.511 | 6.15% | −4.0% |
| 标普500 | (3月, 6%, 4%) | 0.258 | 0.158 | 6.32% | −24.5% |
| 沪金 | (1月, 2%, 32%) | 0.327 | 0.221 | 13.84% | −42.3% |

### 诚实结论

- 🟢 **红利低波50 —— 真正的赢家。** 梭哈把最大回撤从 −46.5% **砍到 −19.2%（腰斩）**，年化还从 4.2% 提到 6.1%，Calmar 是买入持有的 **3.5 倍**。低波慢跌的资产最适合成本线触发。
- 🟢 **沪金 —— 有效。** 年化 9.9% → 13.8%。但回撤改善有限，最优止盈很高（p=32%），是"浅回撤买入 + 高止盈吃大波段"。
- 🟡 **标普500 —— 平淡。** Calmar 1.6 倍但年化反而略降，长牛行情被过早卖出。
- 🔴 **纳指100 —— 陷阱。** Calmar 虚高 3 倍是**假象**：最优参数 p=2%（几乎不涨就跑），疯狂卖出躲过 2022 熊市，却把年化从 18.2% **打到 6.2%**——用丢 2/3 的收益换小回撤，不划算，不建议。

**分层假设（H3）得到验证**：不同波动属性的资产，最优参数显著不同——低波慢跌资产适合成本线触发，高波长牛资产不适合。

**⚠️ 重要提醒**：以上是**样本内**最优网格结果，有过拟合风险。样本外验证（D5）才是判断"红利/沪金是真有效还是历史拟合"的试金石。

## 📖 名词解释（Glossary）

| 术语 | 含义（人话版） |
|------|----------------|
| **定投成本线 (CB)** | 你每天固定投 100 元，把每次买到手的份额按价格加权，就是你"平均花多少钱买一份"。跌到这条线以下 = 你被套了。 |
| **偏离度 (dev)** | 现价相对成本线偏了多少。`dev = P/CB − 1`，负值 = 现价低于成本线。 |
| **回撤 / MaxDD** | 从最高点往下摔多少 / 一辈子最惨那次从山顶到谷底摔了多少。−46.5% = 最惨时亏了近一半。 |
| **CAGR（年化收益）** | 剔除时间因素，平均每年赚百分之几。6% = 平均一年赚 6%。 |
| **Calmar** | `= 年化收益 ÷ 最大回撤`。衡量"每受一分疼能赚多少"，分越高越好。核心指标。 |
| **窗口 W** | 用多长时间的定投记录算成本线。12 月 = 用最近 12 个月的定投。 |
| **入场回撤 d** | 红绿灯阈值——跌到比成本线低多少就抄底。8% = 低于平均成本 8% 就满仓。 |
| **止盈 p** | 抄底后涨回多少就全卖落袋。16% = 涨回 16% 清仓。 |
| **模式A / 梭哈** | 只有两个动作：跌到位 → 全买；涨到位 → 全卖。没有中间仓位。 |
| **网格搜索** | 把"窗口×回撤×止盈"三个旋钮排列组合成几千种，每种都回测一遍找最赚钱的。 |
| **过拟合** | 翻历史书找出的"最优解"，放到没见过的行情里可能失效。这是最大的坑。 |
